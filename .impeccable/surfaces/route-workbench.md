# Workbench

Mode: Operate. Existing Metritag visual system is preserved.

Audience: platform managers see all tasks; ordinary users see their own data and pending actions. Main job: discover blocked or due work and open the correct task.

First viewport: read-only scope and refresh, a continuous four-metric band, then a wider actionable task list alongside quick links and attention counts. No content-area page heading or decorative hero.

Signature interaction: overview, deadline attention and stage distribution all filter the same scoped task list and focus its filter. Selected scope is visible, and every row opens its real task detail.

Below: all-stage distribution and five actual record updates. Only current-state facts, no inferred history or compliance scores. Single-column narrow layout, table-only horizontal scrolling, live Chinese/English and light/dark themes.

Constraints: server identity and authorization are not connected. Current data and role adapter reuse the existing task module. Frontend filtering is not server enforcement. No visual-system changes or new task creation.
